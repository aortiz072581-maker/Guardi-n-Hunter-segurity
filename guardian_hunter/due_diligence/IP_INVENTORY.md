# Guardian Hunter — IP / License Inventory

## Required diligence records

- source-code ownership
- contributor ownership
- third-party dependencies
- dependency licenses
- generated assets
- documentation ownership
- trademarks and product names
- open-source obligations
- external service dependencies

## Buyer-readiness requirement

Every material component should have an identifiable provenance.

Unknown provenance must be recorded as an open diligence item rather
than represented as cleared IP.
